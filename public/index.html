API de Cursos

Examen - Aplicaciones Híbridas

¿De qué trata esta API?

Esta API REST permite gestionar compras, cursos y usuarios en una plataforma educativa (modalidades online, híbrido y presencial). Está pensada para desarrollo local y pruebas en el examen.

Breve descripción

Provee endpoints para crear, listar, actualizar y eliminar compras, usuarios y cursos.

Contexto en pocas palabras

Desarrollada como trabajo para la materia Aplicaciones Híbridas (Comisión DWN4AV). Simula un backend de venta de compra para ser usado con frontends o herramientas como Postman.

Qué ofrece la API

  • CRUD para Compras, Usuarios y Cursos.
  • Endpoints para obtener por ID y filtrar (ej.: compras por usuario).
  • Ejemplos listos para probar en Postman y una página estática con la documentación básica.

Endpoints disponibles

  • GET /api/cursos — Obtener todos los cursos
  • GET /api/cursos/:id — Obtener curso por ID
  • POST /api/cursos — Crear curso (body JSON) 
    {
              "nombre": "JavaScript Básico",
              "descripcion": "Curso inicial de JS",
              "categoria": "Programación",
              "modalidad": "online",
              "precio": 5000,
              "duracion": 40
                 }
  • GET /api/usuarios — Obtener todos los usuarios
  • GET /api/usuarios/:id — Obtener usuario por ID
  • POST /api/usuarios — Crear usuario (body JSON) 
    {
              "name": "Juan Pérez",
              "email": "juan@example.com",
              "password": "123456",
                  }
  • GET /api/compras — Obtener todas las compras
  • GET /api/compras/:id — Obtener compra por ID
  • POST /api/compras — Crear compra (body JSON) 
    {
                "usuario": "ID_USUARIO",
                "curso": "ID_CURSO",
                "metodoPago": "tarjeta",
                "estado": "pagado"
                }
